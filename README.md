# DSA Practice

LeetCode Data Structures & Algorithms solutions in **C**.

## Structure

```
problems/<number>_<problem_name>/
├── problem.md        # Problem statement
├── solution.c        # LeetCode solution + main() to run it
└── explanation.md    # Human-friendly approach & complexity analysis
```

## Run a solution

```bash
gcc solution.c -o solution
./solution
```
